# 🎮 Vortex Gaming Platform

**Vortex Gaming** is a next-generation, high-performance web gaming platform featuring a stunning neon-dark UI/UX, real-time balance tracking, and secure database management.

## ✨ Key Features
- **10 Exciting Games:** Includes Aviator, Color Prediction, Mines, Plinko, Lucky Slots, Dice Roll, Teen Patti, Penalty Shootout, Shapla Toss (Coin Flip), and Dabu Khela.
- **Dynamic Wallet System:** Real-time point synchronization and transaction updates using Firebase.
- **Manual Payment Gateway:** Seamless Deposit & Withdrawal requests via Mobile Financial Services (Bkash/Nagad/Rocket).
- **Secure Admin Panel:** Protected by a secret passcode to manage users, approve deposits/withdrawals, and monitor platform revenue securely.
- **Immersive UI/UX:** Glassmorphism, 3D hover effects, and a sleek neon-dark aesthetic.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Responsive & Modern UI)
- **Backend & Database:** Firebase Firestore / Realtime Database & Firebase Authentication
- **Hosting:** GitHub Pages / Vercel

## 🔒 Admin Access
- The hidden admin panel is secured with a private security PIN for managing platform operations safely.
